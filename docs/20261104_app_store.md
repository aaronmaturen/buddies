# Fussbuddy on the Mac App Store

What it takes to submit, in order. Steps marked **(you)** need the Apple account; the rest are in the repo.

## One-time setup

1. **(you)** Xcode → Settings → Accounts: sign in with the developer Apple ID. Under Manage Certificates, add **Apple Distribution** and **Mac Installer Distribution**.
2. **(you)** developer.apple.com → Identifiers: register an App ID for macOS with the explicit bundle ID `com.aaronmaturen.buddies`. No capabilities needed.
3. **(you)** developer.apple.com → Profiles: new **Mac App Store Connect** distribution profile for that App ID and the Apple Distribution certificate. Download it and keep it out of the repo (for example `~/Documents/Fussbuddy.provisionprofile`).
4. **(you)** App Store Connect → Apps → New App: macOS, name Fussbuddy, bundle ID `com.aaronmaturen.buddies`, any SKU (for example `fussbuddy`). If the name is taken, the app's display name can stay Fussbuddy with a store name like "Fussbuddy: Desktop Pet".

## Each release

1. Bump `CFBundleShortVersionString` (the version people see) and `CFBundleVersion` (must go up for every upload) in `desktop/Info.plist`.
2. `desktop/store.sh ~/Documents/Fussbuddy.provisionprofile` → `desktop/build/Fussbuddy.pkg`: universal app, signed for distribution, profile embedded.
3. **(you)** Upload the pkg with Apple's Transporter app (free on the Mac App Store; sign in, drag the pkg in, Deliver). It shows up under the app's TestFlight tab after processing.
4. **(you)** Fill in the version page and submit for review.

## Store listing

- Category: Games → Simulation (matches `LSApplicationCategoryType`). Secondary: Entertainment.
- Privacy policy URL: https://buddies.aaronmaturen.com/privacy.html
- Support URL: https://buddies.aaronmaturen.com/support.html
- App Privacy: Data Not Collected.
- Age rating: no objectionable content; the pet can die, which is cartoon and implied.
- Encryption: none (`ITSAppUsesNonExemptEncryption` is false, so no export question per upload).
- Screenshots: `desktop/screenshots/{hello,care,play,calling}.png`, 2880×1800, in that order. `desktop/screenshots/render.sh` redraws them from `screens.html` (the library draws the buddy; the desktop and menus are drawn to match the app).
- Review notes: "Fussbuddy is a menu bar app with no Dock icon. The pet appears in the bottom right corner of the screen; right-click it or use the menu bar icon for care. The egg hatches after 5 minutes."

Draft description:

> Fussbuddy is a little pet that lives on your desktop. It watches your cursor, wobbles when you boop it, and needs looking after: feed it, play "which hand?", give it a gift, clean up after it, give it medicine when it's sick, and turn the lights off at bedtime.
>
> It hatches from an egg and grows up over days, and how you care for it decides what it becomes. It calls when it needs you, and it won't wait forever.
>
> No accounts, no ads, nothing sent anywhere. Just a buddy.

Keywords (100 characters max): `virtual pet,desktop pet,menu bar,cute,companion,buddy,egg,pet game,retro,90s`

## Review risks

- `drawsBackground` in `main.swift` is private API set by key, the only way found to make the web view see-through. It's widely used in shipped apps and string keys aren't caught by Apple's symbol scan, but a reviewer could still reject it.
- `com.apple.security.network.client` is needed by the sandboxed web view even for local files; if asked, say the app makes no network requests.
- Keep other companies' trademarks (Tamagotchi is Bandai's) out of the name, keywords and description; App Review rejects them.
